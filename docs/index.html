🧭 Procedura Guidata: Creare il Bot Telegram in 2 minuti

  1. Apri Telegram e cerca @BotFather (la spunta blu ufficiale).
  2. Invia il comando /newbot, scegli un nome e uno username che finisca con bot.
  3. BotFather ti risponderà dandoti il Token HTTP API. Copialo e incollalo qui sotto.
  4. Apri la chat con il tuo nuovo bot appena creato, premi Avvia e inviagli un messaggio qualsiasi (es. "ciao").
  5. Per trovare il tuo Chat ID, visita: https://api.telegram.org/bot<TOKEN>/getUpdates e cerca il numero in "chat":{"id": 123456789}.

💬 Procedura Guidata: Attivare Notifiche WhatsApp

  1. Aggiungi ai contatti del tuo telefono il numero di CallMeBot: +34 644 59 19 86
  2. Apri WhatsApp e inviagli questo messaggio esatto: I allow callmebot to send me messages
  3. Il bot ti risponderà con la tua API Key personale gratuita.

🚀 Come avviare il monitoraggio sul tuo computer:

  1. Clona o scarica il repository da GitHub: 
    git clone https://github.com/TuoUsername/CUP-Monitor.git
cd CUP-Monitor
  2. Inserisci il file scaricato config.yaml nella cartella principale del progetto.
  3. Installa i requisiti ed effettua il primo accesso SPID una tantum: 
    pip install -r requirements.txt
playwright install chromium
python src/main.py --login
  4. Automatizza l'esecuzione e l'invio notifiche ogni 30 minuti con Task Scheduler di Windows (copia questo comando in PowerShell): 
    $action = New-ScheduledTaskAction -Execute "$PWD\run_bot.bat"
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date) -RepetitionInterval (New-TimeSpan -Minutes 30)
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -StartWhenAvailable
Register-ScheduledTask -Action $action -Trigger $trigger -Settings $settings -TaskName "CUP Marche Monitor" -Force

🛑 Come annullare o fermare il monitoraggio:

Una volta che hai prenotato la visita o l'esame desiderato, puoi fermare il bot in qualsiasi momento:

• Su Windows (PowerShell): 
Unregister-ScheduledTask -TaskName "CUP Marche Monitor" -Confirm:$false
In alternativa: apri Utilità di pianificazione (taskschd.msc) e clicca col tasto destro su "CUP Marche Monitor" > Elimina.
• Su Linux / Mac: Apri il crontab con crontab -e e rimuovi la riga del bot.

Estensione Web Browser per Chrome & Edge

Nessun file da configurare, nessun comando da lanciare. Monitora il CUP direttamente mentre navighi sul web.

1

1. Scarica l'Estensione

Scarica il file ZIP col pulsante qui sotto ed estrailo in una cartella a tua scelta sul tuo PC.

2

2. Carica in Chrome/Edge

Apri chrome://extensions, attiva la "Modalità sviluppatore" e clicca su "Carica estensione non pacchettizzata" selezionando la cartella estratta.

3

3. Avvia il Monitoraggio

Clicca sull'icona dell'estensione in alto a destra, inserisci NRE e Codice Fiscale, ed effettua il login SPID normalmente nel browser.
