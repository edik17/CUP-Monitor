🚀 Come avviare il monitoraggio sul tuo computer:

  1. 1
    Clona o scarica il repository da GitHub: 
    git clone https://github.com/edik17/CUP-Monitor.git
cd CUP-Monitor
  2. 2
    Inserisci il file scaricato config.yaml nella cartella principale del progetto.
  3. 3
    Installa i requisiti ed effettua il primo accesso SPID una tantum: 
    pip install -r requirements.txt
playwright install chromium
python src/main.py --login
  4. 4
    Automatizza l'esecuzione e l'invio notifiche ogni 30 minuti con Task Scheduler di Windows: 
    $action = New-ScheduledTaskAction -Execute "$PWD\run_bot.bat"
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date) -RepetitionInterval (New-TimeSpan -Minutes 30)
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -StartWhenAvailable
Register-ScheduledTask -Action $action -Trigger $trigger -Settings $settings -TaskName "CUP Marche Monitor" -Force

Vuoi spegnere il PC? Come monitorare a computer spento

Per ricevere le notifiche sul telefono anche a computer spento senza lasciarlo acceso a casa, hai 2 opzioni semplici e gratuite:

  • GitHub Actions (Cloud Gratuito): puoi configurare un'automazione programmata direttamente sul tuo account GitHub che lancia il bot in cloud ogni X minuti e ti manda la notifica su Telegram ovunque tu sia.
  • Mini PC / Raspberry Pi / Serverino domestico: consuma pochissima corrente e rimane attivo 24/7 in silenzio.

🛑 Come annullare o fermare il monitoraggio:

Una volta che hai prenotato la visita desiderata, puoi fermare il bot in qualsiasi momento:

• Su Windows (PowerShell): 
Unregister-ScheduledTask -TaskName "CUP Marche Monitor" -Confirm:$false
• Su Linux / Mac: Apri il crontab con crontab -e e rimuovi la riga del bot.
