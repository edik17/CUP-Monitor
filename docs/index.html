🧭 Procedura Guidata: Creare il Bot Telegram in 2 minuti

  1. Apri Telegram e cerca @BotFather (la spunta blu ufficiale).
  2. Invia il comando /newbot, scegli un nome e uno username che finisca con bot.
  3. BotFather ti risponderà dandoti il Token HTTP API. Copialo e incollalo qui sotto.
  4. Apri la chat con il tuo nuovo bot appena creato, premi Avvia e inviagli un messaggio qualsiasi (es. "ciao").
  5. Per trovare il tuo Chat ID, visita: https://api.telegram.org/bot<TOKEN>/getUpdates e cerca il numero in "chat":{"id": 123456789}.

🚀 Come avviare il monitoraggio sul tuo computer:

  1. Clona o scarica il repository da GitHub: 
    git clone https://github.com/edik17/CUP-Monitor.git
cd CUP-Monitor
  2. Inserisci il file scaricato config.yaml nella cartella principale del progetto.
  3. Installa i requisiti ed effettua il primo accesso SPID una tantum: 
    pip install -r requirements.txt
playwright install chromium
python src/main.py --login
  4. Automatizza l'esecuzione e l'invio notifiche ogni 30 minuti con Task Scheduler di Windows: 
    $action = New-ScheduledTaskAction -Execute "$PWD\run_bot.bat"
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date) -RepetitionInterval (New-TimeSpan -Minutes 30)
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -StartWhenAvailable
Register-ScheduledTask -Action $action -Trigger $trigger -Settings $settings -TaskName "CUP Marche Monitor" -Force

Vuoi spegnere il PC? Come monitorare a computer spento

Per ricevere le notifiche sul telefono anche a computer spento senza lasciarlo acceso a casa, hai 2 opzioni semplici e gratuite:

  • GitHub Actions (Cloud Gratuito): puoi configurare un'automazione programmata direttamente sul tuo account GitHub che lancia il bot in cloud ogni X minuti e ti manda la notifica su Telegram ovunque tu sia.
  • Mini PC / Raspberry Pi / Serverino domestico: consuma pochissima corrente e rimane attivo 24/7 in silenzio.

🛑 Come annullare o fermare il monitoraggio:

Una volta che hai prenotato la visita desiderata, puoi fermare il bot in qualsiasi momento:

• Su Windows (PowerShell): 
Unregister-ScheduledTask -TaskName "CUP Marche Monitor" -Confirm:$false
• Su Linux / Mac: Apri il crontab con crontab -e e rimuovi la riga del bot.

Come usare il monitoraggio su Smartphone quando sei in giro

Le soluzioni più semplici ed efficaci per avere le notifiche istantanee ovunque ti trovi.

💬 Notifiche Push Telegram (Consigliato) Zero App Extra

Il metodo migliore sia su Android che su iPhone: non richiede app o browser particolari.

  • Ricevi una notifica push immediata con suono e vibrazione sull'app Telegram del tuo smartphone.
  • Dalla notifica tocchi direttamente il link e prenoti la visita in 10 secondi.
🌐 Configurazione 100% Mobile Tutti i Browser

Questo sito web è completamente ottimizzato per touchscreen e responsive:

  • Funziona nativamente su qualsiasi browser per cellulare (Chrome, Safari, Brave, Samsung Internet, Firefox, Edge).
  • Puoi compilare la ricetta e generare il file di configurazione direttamente dallo smartphone.

🛑 Come annullare o fermare il monitoraggio:

Una volta trovata la prenotazione, fermare il monitoraggio è immediato:

  • Metodo 1: Clicca sull'icona dell'estensione in alto a destra nel browser e premi il pulsante rosso "Ferma Monitoraggio".
  • Metodo 2: Da chrome://extensions puoi disattivare o rimuovere l'estensione con un singolo click.
